🧠 Why This Is Important

Without rate limiting:
Client
  │
  ├── Request
  ├── Request
  ├── Request
  ├── Request
  ├── Request
  └── 10,000 Requests
          │
          ▼
       API ❌

A malicious or buggy client can overload your application.

With a distributed rate limiter:
             Client
                │
                ▼
          API Gateway
                │
                ▼
             Redis
          Rate Counter
                │
        ┌───────┴───────┐
        ▼               ▼
   Allowed           Rejected
        │               │
        ▼               ▼
      API          HTTP 429
🎯 Example Rule

We'll implement:

100 requests / minute / client

Example:

Request 1   → ✅
Request 2   → ✅
...
Request 100 → ✅
Request 101 → ❌ 429 Too Many Requests

After the one-minute window expires, the client can make requests again.
